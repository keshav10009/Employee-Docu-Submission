# Employee Document Submission

A responsive Employee Center-style web application for submitting and validating new hire documents.

## Overview

This project provides a simple employee document submission interface with a responsive layout, client-side validation, and API contract documentation.

The application is built using HTML, CSS, and JavaScript.

## Features

- Employee document submission form
- Client-side form validation
- Responsive desktop and mobile design
- Submission status and validation messages
- API request and response examples
- HTTP status code documentation
- Employee Center-style user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenAPI
- Git
- GitHub
